# Noto Sans

`NotoSans.ttf` используется для PDF с русскими и казахскими символами и воспроизводимых OCR fixtures.

Источник: https://raw.githubusercontent.com/google/fonts/main/ofl/notosans/NotoSans%5Bwdth,wght%5D.ttf

Получен 14.10.2026. Лицензия SIL Open Font License 1.1 находится рядом в `OFL.txt`. Файл хранится в репозитории; загрузки шрифта при запуске нет.
