# Бесплатные AI-провайдеры — T056

Проверено 16.10.2026. Пользователь разрешил бесплатные запросы и переключение при отказах. Ключи находятся только в локальном `.env.local` вне Git. На другой машине их нужно задать в серверном окружении. Не копировать ключи в документацию, клиентский код или PR.

## Выбранная конфигурация

`ASSISTANT_PROVIDER=free` выбирает **Gemma 4 26B A4B через Gemini API**, при инфраструктурной ошибке — **Nemotron 3.5 Super VL :free через OpenRouter**. Если Google-ключа нет, начинает с OpenRouter. Один запрос модели — максимум две попытки для этой конфигурации; один экземпляр провайдера не повторяется. `ASSISTANT_MODEL` в режиме `free` намеренно не меняет фиксированную цепочку.

Для синтетической локальной демонстрации: `ASSISTANT_SYNTHETIC_DATA=1`, `LOCAL_PREVIEW=1`, `LOCAL_DATABASE=1`, без `DATABASE_URL`. Команды `npm run dev` и `npm run preview` выставляют LOCAL-флаги. Эта отметка — утверждение оператора о синтетических данных, а не автоматическое распознавание персональных данных.

С этим opt-in разрешены маршруты, на которых поставщик может сохранять/использовать запросы. Без него Google-адаптер отключён, OpenRouter отправляет `data_collection: deny`. Настройки приватности аккаунта не меняются. Для реальных документов сначала согласовать обработку данных и выбрать соответствующий маршрут.

`ASSISTANT_PROVIDER=gemini` / `openrouter` выбирает один адаптер; `ASSISTANT_MODEL` тогда разрешает выбрать поддержанную модель. `disabled` полностью выключает модель, даже если ключи заданы. При отсутствии переменной сохраняется прежний Anthropic-режим. В `.env.example` по умолчанию `disabled`.

## Что именно бесплатно

- OpenRouter: только точный ID с `:free`, проверка текущего каталога перед каждой генерацией (все опубликованные компоненты цены равны нулю), `max_price` prompt/completion/request = 0, без маршрутизации на платную модель, без плагинов, без повторов SDK. Ответ с отсутствующей/ненулевой стоимостью отклоняется. Неподходящий каталог останавливает вызов. HTTP 404/429/5xx может переключить на следующий заранее настроенный бесплатный адаптер.
- Gemini API: allowlist `gemma-4-26b-a4b-it`, `gemma-4-31b-it`. По официальному тарифу на дату проверки вход/выход Gemma 4 бесплатны, платный тариф отсутствует. Автоматической проверки будущих изменений тарифа у Google нет: пересмотреть его перед следующим использованием после изменения условий. Gemini Flash/Pro, платный поиск, генерация изображений и hosted tools здесь не подключены.
- xAI/Grok: официальный запрос списка моделей дал HTTP 400; бесплатная генерация не подтверждена, адаптер не включён.
- Бесплатный OpenRouter-аккаунт при первичной проверке сообщил 50 запросов в сутки. Это общая квота ключа, не 50 на каждую модель. Один бизнес-вопрос может потребовать несколько запросов. Переключение моделей не увеличивает квоту аккаунта.

## Почему этот выбор

Короткое сравнение на одинаковом синтетическом вопросе RU/KK, вызове `finance_summary` и ответе по `12550` тиын:

| Модель / маршрут | Результат |
| --- | --- |
| Gemma 4 26B / Google | 2/2 полных циклов, верные суммы; ~9,6–11,4 с на цикл. Ответ KK понятнее, чем у Nemotron. `125,5` и `125,50` — одна сумма. |
| Nemotron 3.5 Super VL / OpenRouter | 2/2, верные суммы, стоимость обоих циклов в API = 0; ~5,0–7,3 с. В KK заметны языковые ошибки. |
| Nemotron Lightning / OpenRouter | Таймауты, законченного ответа не получено. |
| Gemma 4 31B / OpenRouter | HTTP 429. |
| Gemma 4 31B / Google | Таймауты 25 с. |

Это предварительный выбор для демо по малому набору, не общий рейтинг качества и не полная приёмка T056. Доступность бесплатных моделей меняется.

## Переключение и защита операций

Переключение происходит внутри `budgetedComplete` только при недоступности/лимите/ошибке доступа/таймауте провайдера. Перед каждой попыткой заново проверяются текущие права и бюджет организации. Неизвестный исход сохраняет полный резерв; успешный ответ учитывается по фактическим токенам, включая reasoning-токены. В истории использования записывается фактически ответивший провайдер.

Отказ модели, неправильный ответ API, превышение входа/бюджета, отзыв прав и отмена не обходятся запасной моделью. Инструменты выполняются только после принятого ответа; запрос следующей модели получает уже имеющиеся tool results. Прежние авторизация, область организации/филиала, идемпотентность и разрешённые операции сохраняются. Модель не имеет инструмента для платежа или произвольного SQL. Opaque подписи Google хранятся только в памяти текущего цикла, reasoning не попадает в чат или БД.

Подсчёт входа бесплатных адаптеров — консервативная оценка по UTF-8 байтам полного запроса + 1024, а не точный токенизатор. Крупный контекст может быть отклонён раньше фактического лимита. Действуют существующие допуск 11000 / резерв 12000 + output и блокировка при неожиданном превышении.

Полный `eval:assistant` по-прежнему требует `--confirm-budget`. Для двух адаптеров верхняя граница резервов 32 × 6 × 2 × 16000 = 6 144 000; скрипт рассчитывает её по доступной конфигурации. Бесплатность денег не отменяет расход квоты. По умолчанию e2e выставляет `ASSISTANT_PROVIDER=disabled` и не обращается к внешним моделям.
