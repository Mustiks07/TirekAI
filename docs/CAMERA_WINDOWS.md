# Камеры на Windows: проверка, демо, подключение (T057)

Всё работает локально на компьютере: кадры не уходят во внешние сервисы и не пишутся на диск. Лица не распознаются. Статус подсчёта — **экспериментальный**, пока он не проверен на записях вашего магазина.

## 1. Обновить и скачать модель (один раз)

```powershell
git pull
npm install
npm run video:model          # RF-DETR Nano, ≈ 108 МБ, в .data\models
```

За прокси: `$env:NODE_USE_ENV_PROXY="1"; npm run video:model`. Прежняя модель `dfine-n` больше не используется: на проверке она не видела людей (docs/LOCAL_MODELS.md, «Почему сменили модель»).

## 2. Быстрая проверка камеры без приложения (30 секунд)

Точное имя камеры:

```powershell
ffmpeg -hide_banner -list_devices true -f dshow -i dummy
```

Проверка (встаньте перед камерой, потом отойдите):

```powershell
npm run video:check -- --webcam "video=HD User Facing" --seconds 30
```

Каждую секунду печатается `people now N`, лучшая оценка человека (`best score`) и входы/выходы через линию. В конце строка `Diagnosis`:

| Диагноз | Что значит | Что сделать |
| --- | --- | --- |
| `ok` | люди найдены и посчитаны | — |
| `no_frames` | кадры не пришли | проверить имя камеры; закрыть программу, которая её держит (Zoom, Teams, браузер, запущенный обработчик) |
| `unusable_frames` | все кадры слишком тёмные/светлые/застывшие | свет, крышка камеры |
| `model_sees_nobody` | модель не нашла человека с уверенностью ≥ 0,5 | свет, расстояние 1–4 м, человек целиком или по пояс в кадре; `best score` покажет, насколько близко |
| `tracker_drops` | человек мелькает, но не держится 3 кадра подряд | двигаться медленнее, не уходить за край кадра |
| `outside_zone` | люди посчитаны, но не в зоне | перерисовать зону (центр рамки человека должен быть внутри) |

Результат можно сохранить: `--report docs\evidence\my-camera.json` (в отчёте только числа, без кадров). Пришлите его — это доказательство для вашей камеры; без него «камера исправлена» не заявляется.

## 3. Показ на хакатоне в приложении

```powershell
npm run preview              # http://127.0.0.1:3000
```

«Камеры» → «Проверка на видео»:

- **«Включить камеру этого устройства»**: встаньте перед камерой. Вокруг вас появится рамка «Человек 1», «Сейчас в кадре» = 1. Пройдите поперёк кадра через жёлтую линию: «Вошли» или «Вышли» растут по направлению стрелки. «Нарисовать линию входа» — два нажатия по кадру. «Поменять направление входа» — если считает наоборот.
- **«Выбрать видеофайл»**: запись из магазина (MP4 H.264 или WebM). Видео проходит кадр за кадром с рамками, счётчики (в кадре, вошли/вышли, разных людей, максимум одновременно, среднее время в кадре) растут сразу.
- «Остановить и выключить камеру» освобождает камеру. Если камеру уже держит обработчик (пункт 4), браузер скажет «Камера занята» — одну физическую камеру одновременно открыть нельзя.

Открытые записи людей для демо (лицензия CC BY 4.0, укажите «Intel IoT DevKit sample videos»):

```powershell
mkdir .data\eval\videos -Force
curl.exe -L -o .data\eval\videos\people-detection.mp4 https://raw.githubusercontent.com/intel-iot-devkit/sample-videos/master/people-detection.mp4
curl.exe -L -o .data\eval\videos\store-aisle-detection.mp4 https://raw.githubusercontent.com/intel-iot-devkit/sample-videos/master/store-aisle-detection.mp4
```

`.data` в Git не попадает.

## 4. Камера через обработчик (постоянный подсчёт)

1. «Камеры» → «Добавить камеру» (тип «Веб-камера компьютера»).
2. «Настройки камеры»: нарисуйте линию входа и при необходимости зону, «Сохранить новую версию разметки».
3. «Выдать токен обработчика» — показывается один раз. В PowerShell:

```powershell
$env:VIDEO_DEVICE_TOKEN="<токен>"
npm run video:processor -- --server http://127.0.0.1:3000 --source <id камеры> --webcam "video=HD User Facing"
```

4. «Обзор»: «Онлайн: поток поступает», «Сейчас видно людей», «Вошли/Вышли сегодня», время обновления. «Показать видео» — последний обработанный кадр с рамками (передаётся только пока экран открыт; «Скрыть видео» останавливает показ, но не подсчёт).
5. Запись магазина как «камера» для демо: вместо `--webcam …` укажите `--file .data\eval\videos\people-detection.mp4 --loop`.

Остановка: `Ctrl+C` в окне обработчика — прогон закрывается, ffmpeg и камера освобождаются.

**Перевыпуск токена** («Перевыпустить токен» с подтверждением) сразу отключает обработчик со старым токеном: он напишет «Сервер не принял токен устройства…», остановится и освободит камеру. Запустите его с новым токеном. Если у вас есть свой скрипт обновления токена (в `.local\`), он должен отправлять тело `{"replace": true}` — без него сервер отвечает 409 `VIDEO_TOKEN_REPLACE_CONFIRM`.

На экране «Поступает N кадр/с» — сколько кадров реально обработано за секунду; «обработка до M кадр/с» — сколько успевала бы модель. Если N заметно меньше 5, компьютер не успевает: это не ошибка, просто реже обновления.
