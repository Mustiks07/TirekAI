# Безопасность основания

Реализовано: серверные memberships; параметризованный SQL; allowlist ролей и профилей; branch scoping; составные FK; транзакции; случайные 256-bit session/invite токены и хранение только hash; scrypt N=32768,r=8,p=1; HttpOnly/SameSite=Lax cookies; Secure при HTTPS; проверка Origin для мутаций; ограничение размера JSON; лимит 8 попыток входа за 15 минут на email; 12-часовые сессии; 48-часовые одноразовые приглашения; запрет выдачи owner через invite; повторная проверка создателя; отзыв всех сессий исключённого сотрудника.

Логи ошибок содержат только код и requestId. Аудит содержит тип операции и роль, без паролей, токенов, почтовых адресов и тел запросов. Приглашение возвращается создателю один раз; фрагмент URL не отправляется серверу при переходе. Email остаётся видимым самому участнику и лицам с правом чтения команды.

Локальная саморегистрация подтверждает только владение сессией, не email. Поэтому режим предназначен исключительно для синтетических данных, слушает loopback и явно помечен. Внешняя саморегистрация закрыта. Это не готовая identity-система для реальных организаций.

До живого запуска: доверенный identity-провайдер или подтверждение email, восстановление аккаунта, MFA owner/admin, независимая проверка криптографии и сессий, распределённые лимиты/IP, срок хранения и очистка auth_limits, CSP, приглашения по проверенному каналу, RLS/DB grants, пагинация, нагрузка, резервное копирование и восстановление. Права чувствительных финансовых полей, worker/export/AI/realtime будут проверяться при появлении этих поверхностей. Текущие тесты не подтверждают ещё не реализованные пути.

Администратор платформы не реализован. UI не предоставляет административного обхода чужих memberships. Действия с камерой и микрофоном сейчас заблокированы Permissions-Policy; их включение потребует отдельной реализации и явного действия пользователя.

`.data`, `.local`, `.env`, логи и результаты тестовых трасс исключены из git. Они также исключены из server tracing. Fixtures используют уникальные случайные пароли, записанные в игнорируемый локальный файл. Не копировать этот файл в артефакты или переписку.
