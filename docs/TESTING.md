# Проверки первого среза

Стенд: Windows, Node.js 22.20.0, npm 10.9.3, Edge. Дата: 14.10.2026. PGlite in-memory для integration; отдельный файловый PGlite для e2e. Это контролируемые синтетические данные.

## Сервер

`npm test`, `tests/foundation.test.ts`: 15 тестов.

- Повторное применение миграции и неизменность истории.
- Хеши паролей/сессий и проверка неверного пароля.
- Только свои организации; подмена organization_id и анонимный запрос.
- Создание организации, timezone/KZT/synthetic и аудит.
- Правильный email, одноразовое приглашение и права сотрудника.
- Изоляция филиалов для команды и аудита.
- Чужой branch_id не создаёт приглашение.
- Нельзя назначить owner через входные данные.
- Истечение, отзыв и перевыпуск приглашений.
- Два запроса принятия дают один результат.
- Исключение отзывает все сессии; owner защищён.
- Создатель приглашения потерял полномочия.
- Истекшая сессия и logout.
- Лимит неверных попыток входа.
- Rollback при ошибке транзакции.

PGlite сериализует обращения; тест повторов не доказывает конкурентную корректность нескольких PostgreSQL-процессов. Это нужно отдельно проверить с PostgreSQL в T008/T049/T051.

## Браузер

`npm run test:e2e`, `tests/e2e/foundation.spec.ts`: два сценария. Производственная сборка запускается автоматически на `127.0.0.1:3100`. На каждый запуск выделен новый каталог `.data/e2e-*`. Тестовый сервер останавливает Playwright.

Проверяются регистрация, создание организации и филиала, приглашение, вход второго пользователя, принятие, ограничения UI/API, чужая организация, враждебный Origin, HttpOnly cookie, исключение и отзыв сессии, KK/RU, повторное открытие, ширины 360/390/430 px, ошибки браузера и axe WCAG A/AA. Снимки: `docs/evidence/desktop-ru.png`, `desktop-kk.png`, `mobile-kk.png`.

Обнаруженные и исправленные при QA проблемы: подсказка пароля/опции select входили в доступное имя; недостаточный контраст вторичного текста; открытие invite во фрагменте URL уже загруженной вкладки не обрабатывалось до добавления hashchange. Непройденный запуск не считается успешным результатом. Добавлены четыре unit-проверки KK/RU дат и смены календарного дня в часовом поясе организации.

## Не проверено

Docker/PostgreSQL Server, внешние провайдеры, restore из резервной копии, нагрузка 20 пользователей, p95, обновления realtime, PWA, workers, деньги, импорт, AI eval, video eval и отрасли. Автоматическая accessibility-проверка не заменяет проверку экранным диктором и полный аудит всех будущих модулей.

## Команды

`npm run lint`, `npm run typecheck`, `npm test`, `npm run build`, `npm run test:e2e`, `npm audit`.

CI повторяет основные команды и устанавливает Chromium. Workflow ещё не запускался удалённо. Browser traces с данными тестовых форм сохраняются только в игнорируемых `test-results` / `playwright-report`.
