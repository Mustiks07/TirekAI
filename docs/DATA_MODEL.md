# Данные и инварианты

| Таблица | Назначение и ограничения |
| --- | --- |
| users | UUID, уникальная нормализованная почта, имя, scrypt hash |
| sessions | SHA-256 случайного токена, пользователь, абсолютное истечение через 12 часов |
| organizations | UUID, название, профиль, KZT, timezone, synthetic |
| branches | Уникальное имя внутри организации; составной ключ организации и UUID |
| memberships | Один пользователь один раз в организации, роль, опциональный филиал; owner имеет доступ ко всем филиалам |
| invitations | Email, ограниченная роль, филиал, hash, создатель, истечение, принятие, отзыв |
| audit_events | Организация, филиал при наличии, автор, тип, минимальные детали, время UTC |
| auth_limits | Hash ключа попыток, число, окно 15 минут |
| schema_migrations | Версия, checksum, время применения |

Внешний ключ `(organization_id, branch_id)` запрещает ссылку на чужой филиал даже при ошибке приложения. Проверка выполняется также в сервисе для понятного отказа.

Организация, owner membership, первоначальный филиал и событие создания записываются одной транзакцией. Приглашение принимается с блокировкой записи и проверкой актуальных полномочий создателя. Повтор не создаёт membership. Новый invite того же email отзывает предыдущий.

Удаление сотрудника удаляет membership и все его сессии, сохраняя пользователя и историю. Owner исключить нельзя. Токены и пароли не попадают в audit. Время хранится как `timestamptz`, отображается в часовом поясе организации.

Глобальная учётная запись не содержит бизнес-данных. Чужая membership, email и история не попадают в ответы неавторизованному пользователю. Сотрудник видит только себя, manager видит команду в разрешённом филиале. Организационные события без филиала не раскрываются филиальному управляющему.

Миграция 2 добавляет `customers`, `import_batches`, `import_rows`, `outbox_events`, `jobs`, `worker_heartbeat`. Ссылки между бизнес-таблицами включают organization_id. Клиент уникален по `(organization_id,branch_id,external_id)`. Это namespace источника CSV внутри филиала; разные филиалы могут иметь одинаковые external_id. Смена файла не меняет этот namespace.

Пакет уникален по организации, филиалу и SHA-256 содержимого + разделителя (BOM/CRLF нормализуются). Имя файла на повтор не влияет. Сохраняются исходный текст, дата, номер физической строки, нормализованные поля, ошибки и статусы. Тексты синтетических файлов остаются в локальной БД; автоматического удаления пока нет. Клиент хранит ссылку на исходный пакет и строку, изменение контакта не меняет происхождение.

Подтверждение создаёт уникальное outbox-событие, dispatcher — одно задание на пакет. Lease-token ограждает запись старым обработчиком; 30-секундный lease, до 3 попыток неуспешной порции, задержка 2 секунды. Успешная порция сбрасывает счётчик попыток. Завершение создаёт одно событие `import.completed`; его потребителей пока нет. Ошибки/конфликты дают `partial`, права отозваны — `cancelled`. Явный retry записывает нового инициатора и продолжает готовые строки.

В `domain/decimal.ts` значения принимаются строками: до 15 целых и 6 дробных цифр. Количества/цены неотрицательны, возврат денежных сумм может быть отрицательным. Денежные минимальные единицы — bigint; HALF_UP применяется к итоговой сумме строки после умножения, не к промежуточной цене. При нулевой выручке маржа null. Денежных и складских таблиц ещё нет; эти примитивы должны использоваться в T010/T015 вместо float.
