Показатели экрана «Сегодня» получены из API организации, состава участников, филиалов и аудита. Финансовых графиков с выдуманными значениями нет. Материалы документов и все будущие требования остаются в TASKS.md / TRACEABILITY.md.

Ограничения: PGlite в одном локальном процессе, синтетические данные, нет подтверждения email/MFA/recovery, общей приёмки, нагрузки или подтверждённого восстановления из backup. PostgreSQL проверен на изолированном локальном сервере 18.2. Живые интеграции и размещение не выполнялись.

Проверки среза: 54 unit/integration/process + 7 PostgreSQL + 5 e2e, lint/typecheck/build, npm audit без известных уязвимостей. Подробные границы подтверждения в TESTING.md. Локальные web, worker и временный PostgreSQL при передаче остановлены.
