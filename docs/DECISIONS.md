# Решения

## ADR-001: локальный первый срез, 14.10.2026

Пустой Git-репозиторий TarazHackathon подтверждён. Исходные документы скопированы без изменения. Ветка `codex/foundation`. Разрешение «можешь начинать» использовано для локальной разработки. Публикация, внешние аккаунты и реальные данные не требуются для первого результата.

## ADR-002: Next.js и модульный монолит

Следуем стеку ТЗ: Next.js/React/TypeScript, SQL-интерфейс к PostgreSQL. Версии проверены в npm и закреплены lockfile. Структура отделяет HTTP, сервис, права, DB и UI. Документация: [Next installation](https://nextjs.org/docs/app/getting-started/installation), [authentication](https://nextjs.org/docs/app/guides/authentication).

## ADR-003: PGlite только для локальной синтетической среды

Docker CLI установлен, Docker Engine не запущен. Чтобы не менять настройки системного Docker, для локальной работы используется PGlite с диском, а для внешней БД подготовлен pg driver. PGlite одноподключённый: положительный тест не доказывает PostgreSQL-конкуренцию, lock semantics при нескольких процессах или нагрузочные цели. Это явная альтернатива окружения, не смена целевой архитектуры. [Документация PGlite](https://pglite.dev/docs/).

## ADR-004: локальная identity

Собственная ограниченная сессия для первого тестового сценария. Случайные opaque tokens вместо JWT, серверный отзыв; scrypt через [Node crypto](https://nodejs.org/docs/latest-v22.x/api/crypto.html). Открытая регистрация разрешена только локально, все организации synthetic. Провайдер, подтверждение почты и MFA остаются в T003 до живого запуска. Нет общих публичных паролей.

## ADR-005: документы задач восстановлены

В предоставленных файлах есть ссылки на T001–T058, но исходного TASKS.md нет ни в проекте, ни среди найденных файлов комплекта. Новый TASKS.md восстанавливает смысл по DEVELOPMENT_PLAN.md. Зависимости помечены рабочими. При получении оригинала сверить и дополнить, не затирая доказательства.

## ADR-006: профиль сохраняется без заявления отраслевой готовности

В форме доступны все восемь профилей. Сейчас это параметр организации, без восьми фиктивных модулей. Рабочие разделы: Сегодня, Команда, Организация, История. Остальной объём сохраняется в задачах.

## ADR-007: линтер без уязвимой транзитивной цепочки

`npm audit` обнаружил advisory GHSA-vfj7-8cjw-p6xm через eslint-config-next → fast-glob → micromatch → braces 3.0.3. Исправленной версии braces при проверке не было. Вместо downgrade Next установлен явный flat config ESLint + typescript-eslint + react-hooks + jsx-a11y. ESLint 9.39.5 выбран из-за peer range jsx-a11y; помечен поставщиком deprecated, миграция на ESLint 10 ожидает совместимого plugin. После изменения npm audit сообщил 0 уязвимостей. Next build отдельно проверяет TypeScript.
